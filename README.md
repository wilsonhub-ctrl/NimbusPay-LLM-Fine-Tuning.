# NimbusPay LLM Fine-Tuning Assignment

## Project Overview
This project fine-tunes an open-source language model to classify NimbusPay customer support tickets and generate structured JSON outputs.

## Model
- Base model: Qwen/Qwen2.5-1.5B-Instruct
- Fine-tuning: LoRA
- Framework: Hugging Face Transformers and PEFT
- Environment: Google Colab with GPU

## Dataset
The assignment uses training, development, and test datasets. Data auditing, label correction, transaction ID normalization, and quoted-history cleaning are documented in the notebook.

**Note:** Assignment datasets and base model files are not included in this repository.

## Notebook
See `NimbusPay_LLM_Fine_Tuning_Final.ipynb` for the complete workflow, including data preparation, baseline evaluation, fine-tuning, experiments, and test prediction generation.

## Results
Historical baseline and FP16 LoRA results are documented in the notebook. Remaining experiments and final test predictions must be generated by executing the notebook.
